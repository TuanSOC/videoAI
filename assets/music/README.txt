Background music, sorted by mood. The script model tags each video with one mood and the render
picks a track from that folder (any folder if it is empty). Only use tracks you may publish:
- YouTube Audio Library (studio.youtube.com, Audio library, "no attribution required")
- Pixabay Music (pixabay.com/music)
- Incompetech / Kevin MacLeod (incompetech.com): CC BY 4.0, monetisation allowed, credit REQUIRED
Formats: mp3, m4a, wav, ogg. A few tracks per mood is enough; a video keeps its track on re-render.

Credits: put the license's attribution text in <track>.credit.txt next to the track; the video
description then gets a "Music:" section automatically. Tracks without one are not credited.

Installed (Incompetech, CC BY 4.0; the mp3 files are not in git — re-download from
https://incompetech.com/music/royalty-free/mp3-royaltyfree/<Title>.mp3):
  tense      Hitman, Volatile Reaction, Aggressor
  mystery    Investigations, Spy Glass, Hidden Agenda
  calm       Wallpaper, Dreamy Flashback, Floating Cities
  upbeat     Carefree, Life of Riley, Sneaky Snitch
  inspiring  Inspired, Heroic Age, Rising Game
